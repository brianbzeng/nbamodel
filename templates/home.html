NBA Odds Predictor

A Basketball-Reference scraper plus an Elo model that turns completed NBA games into a live, browser-based leaderboard.

The project stays intentionally narrow: pull games, normalize them, update ratings, and present the current state of the model with enough detail to explain what is happening.

Scraping

  • Basketball-Reference regular-season pages are parsed season by season.
  • Only finished games are written to the raw CSV output.
  • Current-season scrapes only include games that have already been played.

Cleaning

  • Team names are normalized into NBA abbreviations such as BOS, GSW, and DEN.
  • Game rows are stamped with `home_win` and `margin` for model input.
  • Processed data is saved so the leaderboard can be rebuilt on demand.

Elo updates

  • Every team starts from a 1500-point prior rating.
  • Home-court advantage shifts the expected win probability upward for the home team.
  • Margin of victory scales the size of the update when results are more or less surprising.

Outputs

  • The leaderboard reflects the live current-season ratings, or the most recent season if the current one has not started yet.
  • Ratings can be refreshed from the latest scrape at any time.
  • Data files can be reset if a scrape gets messy or you want to start over cleanly.

What 1500 means

In this project, 1500 is the prior rating assigned to every team before the model sees any games. It is not a points-scored stat, just a shared starting belief.

  • Expected performance is measured as a difference relative to that baseline.
  • Ratings above 1500 indicate a team has outperformed the prior.
  • Ratings below 1500 indicate a team has underperformed the prior.
