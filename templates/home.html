What it does

  • Scrapes regular-season NBA results
  • Cleans and normalizes team names into abbreviations
  • Runs an Elo model with home-court advantage and margin weighting
  • Saves processed CSV outputs for analysis and presentation

How the pipeline works

  1. Scrape game results from Basketball-Reference.
  2. Clean the data and normalize team names.
  3. Run Elo ratings across the full season history.
  4. Render the latest standings on the leaderboard page.

Bayesian Elo

The model treats each team rating like a belief that gets updated after every game. Ratings begin at a shared prior, then move toward a posterior estimate based on the result and how surprising it was. A favorite winning by a lot shifts the rating only a little, while an underdog win creates a larger update because the evidence contradicts the prior more strongly.

That is the core Bayesian idea here: start with a prior, observe evidence, and update the estimate rather than replacing it. The result is a rating system that is simple enough to explain, but still feels probabilistic and data-driven.
