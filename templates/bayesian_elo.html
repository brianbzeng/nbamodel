Method

Bayesian Elo, written out

This page separates the exact Bayesian benchmark from the Elo-style approximation used in the app so the math is explicit and easy to inspect.

1. A true conjugate benchmark

If we were modeling a single team's win probability as a fixed parameter, the clean conjugate pair is a Beta prior with a Bernoulli likelihood.

θ ∼ Beta ( α0 , β0 ) y | θ ∼ Bernoulli ( θ ) p ( θ | y ) ∝ p ( y | θ ) p ( θ ) p ( θ | y ) ∝ θ α0+y−1 (1−θ) β0 + (1−y) − 1 θ | y ∼ Beta ( α0+y , β0+1−y )

That is the exact conjugate story, but it is not the rating system this app uses.

2. The prior used in this app

Each team starts with the same prior rating centered at 1500:

ri ∼ N ( 1500 , σ02 )

Here, 1500 is only the shared starting belief. It is not a point total or an offensive stat. It is a baseline around which ratings move up or down as game evidence arrives.

3. Likelihood and expected win probability

The app uses the standard Elo logistic curve for the home team's expected win probability:

phome = σ ( rhome − raway + h s ) = 1 1 + e − rhome − raway + h s
  • h is the home-court advantage bonus, set in the model as a fixed shift.
  • s is the rating scale factor that controls how quickly probability changes with rating gaps.
  • Differences in ratings translate into probabilities, not directly into points scored.

4. Posterior update used by the model

Because the logistic likelihood is not conjugate with the Gaussian prior, the app uses an online approximation instead of a closed-form posterior. The update rule is:

rhome (new) = rhome + K ⁢ m ⁢ ( y − phome ) raway (new) = raway − K ⁢ m ⁢ ( y − phome ) m = log ( margin+1 )

The term y - p_home is the surprise term. A result that matches the expectation changes the rating only a little. A surprising upset changes it more.

5. Season regression

Between seasons, ratings are pulled back toward the prior:

r i,next season = λ ⁢ r i,end of season + (1−λ) ⁢ 1500

This keeps the model from becoming overly certain forever and lets new information matter at the start of a season.

What that means in practice

  • A team that keeps winning moves above 1500.
  • A team that loses to expected opponents drifts below 1500.
  • Home court and blowout margin change how large each update is.
  • The leaderboard is therefore a live reflection of the latest live season data.
